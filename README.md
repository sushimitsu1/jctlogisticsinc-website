# JCT Logistics Inc website (static)

Plain HTML/CSS site for https://www.jctlogisticsinc.com. No build step.

- Deploy: GitHub Pages (main, root). Quote form posts to FormSubmit (https://formsubmit.co/info@jctlogisticsinc.com); the first submission sends an activation email to info@ that must be confirmed. When DNS is ready, rename CNAME.pending to CNAME and push.
- Pages: `index.html`, `thanks.html` (form success), `404.html`.
- Assets: `assets/` (hero video mp4/webm + poster, favicon, OG image, logo).
- Naming rule: always "JCT Logistics Inc", never "JCT" or "JCT Logistics" alone.
